## Current Mission: SpectraX Explorer

<div align="center">

### Exploring the Universe Through Infrared Data

**NASA SPHEREx | NASA Space Apps Challenge**

</div>

I'm part of **SpectraX**, a team working on SpectraX Explorer, a scientific web application designed to make astronomical infrared observations easier to explore and understand.

The project focuses on:

- Exploring astronomical objects.
- Visualizing infrared observations.
- Understanding spectral information.
- Making scientific datasets more accessible.
- Helping users learn about astronomical discoveries.

**Technologies:** React, JavaScript, Python and scientific data tools.
